# Result stage gates

- [x] D0: protocol, current datasets, baselines, metrics, software commit, and log
  schema recorded.
- [x] D1: contribution-to-experiment traceability recorded.
- [x] D2: table schema, figure data manifest, and current real raw data recorded.
- [ ] D3: repeated main, efficiency, ablation, and generalization results complete.
- [ ] D4: manuscript result prose contains no planning or placeholder language.
- [ ] D5: independent peer review completed and valid findings resolved.

Open D3 blockers: clean-upstream controls, 1M multilingual real corpus, learned
Sparse strong baselines, filter matrix, repeated-run confidence intervals, router
regret, CPU/cache/RSS, index migration, and update amplification.
